# Shinepal
這是享尼尼泊爾國際志工團的官方網站，之後的最新消息會在這裡公布

網址：https://egor0718-littledino.github.io/Shinepal/

## 檔案說明
| 檔案 | 用途 |
|---|---|
| `index.html` | 整個網站（版面、文字、中英切換都在這一個檔案裡） |
| `p/` | 網站用到的所有照片、影片、音樂與圖示 |
| `p/favicon.png`、`p/apple-touch-icon.png` | 瀏覽器分頁與手機主畫面的老虎圖示 |
| `.nojekyll` | 讓 GitHub Pages 直接照原樣發布檔案，請勿刪除 |

`p/` 裡的照片命名規則：檔名結尾有 `t` 的是縮圖（例如 `731img7676t.jpg`），沒有 `t` 的是放大檢視用的大圖；`wx_01.jpg`～`wx_11.jpg` 是「享尼1415小迎新」相簿。
