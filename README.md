# Shinepal
這是享尼尼泊爾國際志工團的官方網站，之後的最新消息會在這裡公布

網址：https://egor0718-littledino.github.io/Shinepal/

## 這裡面有什麼？

### 📄 `index.html`：網站本身
大家打開網址看到的整個網頁，就是這一個檔案。
文字、排版、顏色、中英文切換，全部都寫在裡面。
想改網站上的字或內容，改的就是它。

### 📁 `p` 資料夾：網站用到的照片和影片
網站上看到的每張照片、每支影片、背景音樂，都放在這裡。
- 檔名最後有 **t** 的（例如 `731img7676t.jpg`）是**小張的預覽圖**，讓網頁開得快
- 檔名最後沒有 **t** 的是**點開後看到的大圖**
- 檔名開頭的數字是拍攝日期，例如 `731` 是 7 月 31 日、`801` 是 8 月 1 日
- `wx_01`～`wx_11` 是「享尼1415小迎新」的相簿照片
- `vid_intro.mp4` 是介紹影片，`vid_bless.mp4` 是孩子們的祝福影片
- `bgm.mp3` 是網站的背景音樂
- `favicon.png` 是瀏覽器分頁上的老虎小圖示，`apple-touch-icon.png` 是手機「加入主畫面」時的圖示
- `sp_` 開頭的是贊助單位的 Logo
- `tee` 開頭的是團服照片，`ic_tee` 開頭的是義賣區的小 T 恤圖示
- `hero.jpg` 是首頁最上面的大合照
- `tiger.jpg` 是整個網頁淡淡的老虎背景，`logo.jpg` 是享尼 Logo
- `burn.jpg` 是燒燙傷衛教課的照片
- 檔名有 `poster` 的，是影片還沒播放時顯示的封面

⚠️ 照片的檔名不要隨便改，改了網站就找不到那張照片。

### 📄 `.nojekyll`：讓網站正常顯示的小開關
一個空白檔案，作用是告訴 GitHub「網站照原樣放上去就好」。
**請不要刪除。**

### 📄 `README.md`：說明書
就是你現在看的這份說明，不會出現在網站上。
